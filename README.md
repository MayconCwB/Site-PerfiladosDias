# Perfilados Dias

Proposta de site estático e refinamento visual da marca, baseada no perfil público https://www.instagram.com/perfilados.dias/.

Identidade: azul #315DFF, azul profundo #111D35 e branco. Logo vetorial inspirada no símbolo existente, com espessuras consistentes e tipografia renovada. A ilustração do topo é um estudo conceitual de forma, não uma fotografia de produto.

Fotografias provenientes das publicações públicas da empresa. Contato direcionado ao Instagram; não foram inventados depoimentos, certificações, números, endereço ou prazos.

Publicação: GitHub Pages, branch main, pasta raiz. Arquivos estáticos sem etapa de compilação. Fontes Google com fallback local.
